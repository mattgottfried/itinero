# Passagio

A native iOS app for planning and tracking trips — cruises and land trips — with day-by-day itineraries,
booking status, and per-traveler plans. SwiftUI + SwiftData, iOS 17+.

```bash
brew install xcodegen
xcodegen generate
open Passagio.xcodeproj
```

See `CLAUDE.md` for architecture and conventions, `DESIGN.md` for the UI system.
